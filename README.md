## Обновление 0.0.2 (сборка Windows 1.1.7)

Исправлен игровой HUD: при включении запускается счётчик FPS, активная игра
выбирается сразу, значения обновляются каждые 250 мс. Температура CPU берётся
из реальных датчиков LibreHardwareMonitor с резервным источником Windows.

Прогресс программ отображается отдельной капсулой справа. Переключатель находится
в «Настройки → Поведение → Прогресс других программ справа».
Буфер обмена хранит текст и скриншоты за 24 часа; нажатие на запись копирует её обратно.
Для изображений есть предпросмотр; удаление записи и очистка истории удаляют и файлы.
На одну картинку допускается до 16 МБ PNG и 32 млн пикселей, на историю — 64 МБ и 100 записей.
Исправлены прозрачность жидкого стекла и переводы всех новых разделов на пять языков.
Глаза персонажей плавно следуют за курсором, у значков без глаз слегка поворачивается фигурка.

## Возможности 1.1.5

Громкость обновляется событиями CoreAudio, независимо от WMI и фонового сканирования.
«Настройки → Поведение → Показ громкости в динамическом острове» заменяет
стандартный Windows OSD для клавиш громкости/отключения звука; выключение
переключателя возвращает обычное поведение Windows. При отсутствии аудиоустройства
или ошибке подключения клавиши пропускаются в систему. Собственные индикаторы
драйверов и изменения звука через сторонние программы не блокируются.
Тень отрисовывается отдельно от содержимого, захват мыши сохраняет жест при
раскрытии/наведении, операции восстановления баннеров выполняются вне UI-потока.

Кнопка «Центр» на главной и пункт «Новые возможности» в меню островка открывают:

- системный микшер: общая громкость, отдельные аудиосессии и отключение звука;
- календарь .ics с повторениями, исключениями, часовыми поясами и переходом
  в Zoom / Meet / Teams / Телемост за 10 минут и в момент начала встречи;
- сохраняемые таймеры и напоминания;
- караоке из локального LRC или LRCLIB (сетевой поиск включается отдельно);
- Gemini Live с выбором голоса, громкостью, текстовыми репликами и открытием
  приложений / HTTPS-сайтов по голосовой просьбе;
- раскладку с перетаскиванием разделов и кнопок, ручной размер островка,
  формат часов, шрифт, скругление, тень, прозрачность в покое и задержку наведения;
- свои темы с переносимым кодом, 22 новых векторных персонажа и вариант без персонажа;
- диагностический отчёт и проверку обновлений из GitHub Releases.

Ключ Gemini шифруется Windows DPAPI для текущего пользователя; поддерживается
также GEMINI_API_KEY. Микрофон запускается только кнопкой «Голос». Для работы
нужны доступная модель Gemini Live, интернет и API-ключ с соответствующим доступом.
Работа с реальным API не проверяется автоматически без ключа.

Календарь обновляется повторным импортом .ics. Поиск LRCLIB передаёт название,
исполнителя и альбом только после включения настройки. Обычный LRC содержит
времена строк: подсветка между ними интерполируется; точные времена каждого слова
таким файлом не задаются. Длинные строки целиком помещаются с уменьшением шрифта.

Прогресс читается из процентов в заголовках окон. Окно без процентов не даёт
достоверного прогресса. При недоступном центре уведомлений резервный режим читает
только счётчик непрочитанных в заголовке мессенджера и открывает его окно;
текст и точный чат доступны через исходное уведомление Windows.

Индикатор яркости доступен экранам, публикующим её через WMI. Переход между
мониторами выключен по умолчанию и использует физические координаты и PerMonitorV2.
Счётчик FPS игры включается вместе с игровым HUD или в «Система» с запросом Windows на права
администратора: встроенный помощник считает DirectX Present через ETW, не пишет
файлы и завершается вместе с приложением. Это частота отправки кадров, не измерение
момента показа каждого кадра. OpenGL/Vulkan могут не публиковать нужные события.
Без доступного датчика температуры или GPU показывается «—», а не оценка по CPU.
Для температуры CPU включите в установщике «Установить PawnIO» или используйте
кнопку установки драйвера в игровом центре. Подписанный PawnIO 2.2.0 включён
в установщик; ручная загрузка не нужна. Отмена установки драйвера сохраняет работу FPS.

Обновления принимают публичный owner/repository. Загрузка отклоняется без
однозначной опубликованной SHA-256 установщика и действительной подписи издателя
CN=DynamicIslandWin. Для публикации достаточно загрузить в GitHub Release
artifacts/ocdynamicisland.exe и artifacts/SHA256SUMS.txt.
Источник по умолчанию: `poweredoutside/dynamic-island-for-windows`.
Он также подставляется при обновлении старых настроек с пустым источником;
явно выбранный пользователем другой репозиторий сохраняется.

Проверки новых функций: `dotnet run --project tests/FeatureChecks/FeatureChecks.csproj`.
Они используют искусственные календари / уведомления и рисуют интерфейс вне экрана;
не включают микрофон, не отправляют сообщения и не изменяют настройки пользователя.

## Установка

Графический установщик: `artifacts/ocdynamicisland.exe`. Это один самостоятельный файл:
пакет и .NET включены внутрь, консоль не открывается. Нажмите «Установить»,
дождитесь завершения и нажмите «Готово». Запуск приложения можно отключить флажком.
При обновлении современная версия приложения закрывается штатно; параметры сохраняются.

В полном комплекте также есть `Setup.cmd` для установки через консоль.
Можно запустить `installer/Setup.cmd` из исходников: он найдёт последнюю
готовую сборку в `artifacts`, независимо от текущей рабочей папки.
Установщик регистрирует пакет MSIX для текущего пользователя; .NET уже включён.
Появляются запись в меню «Пуск», удаление через «Параметры → Приложения»
и поддержка обновления поверх установленной версии с сохранением параметров.

Тестовая сборка подписана собственным сертификатом. Установщик запрашивает
права администратора только для добавления сертификата
издателя в `LocalMachine/TrustedPeople`. При отмене установка прекращается.
Приложение работает с обычными правами. Для публичного распространения нужен
доверенный сертификат подписи кода либо публикация через Microsoft Store.
Приватный ключ `.tools/signing/development.pfx` не включается в установщик и Git.

Повторная установка новой версии: тот же сертификат и большее значение `Version`.
Версия `1.0.1.0 x64` обновляет прежний пакет `1.0.0.0 neutral` без удаления.
Установщик проверяет версию и архитектуру до установки: одинаковая уже установленная
версия распознаётся без переустановки; для смены архитектуры требуется больший
номер версии. Автоматического удаления существующего приложения нет.
Удаление: параметры Windows либо `installer/Uninstall.ps1`. Удаление приложения
не удаляет тестовый сертификат из доверенных издателей; его можно удалить в
`certlm.msc → Trusted People`, сверив отпечаток с `DynamicIsland.cer`.
Настройки прежней переносной версии в `%APPDATA%/DynamicIslandWin` сохраняются.

## Уведомления

После первого запуска разрешите чтение уведомлений в системном запросе Windows.
Обе настройки работают через Windows Notification Listener:

- «Сообщения Telegram, Discord, Viber…» — сообщения распознанных мессенджеров.
- «Уведомления всех приложений» — все системные уведомления, включая мессенджеры;
  работает и при выключенном первом переключателе.

В настройках островка показывается состояние доступа. После отказа используйте
кнопку доступа, чтобы открыть разрешения Windows. Разрешение можно отозвать;
приложение прекращает чтение и обновляет статус. При запуске EXE напрямую без
пакетной идентичности выводится пояснение о необходимости установки MSIX.

Новое уведомление показывается сразу, заменяя предыдущее. В серии одновременно
полученных уведомлений показывается последнее; полная история остаётся в Windows.
Подсказки клавиатуры и буфера обмена не перебивают сообщение.
В «Настройки → Поведение» можно выбрать время показа от 3 до 10 секунд
(по умолчанию 5); значение сохраняется между запусками.
Значок загружается из приложения-источника, а для настольных приложений без
логотипа — из их точной записи Windows AppsFolder. Загрузка выполняется в фоне,
успешные значки кэшируются. Пока значок загружается или если источник недоступен,
показывается символ конверта. exDesktop распознаётся как мессенджер вместе с Telegram и Discord.
Нажатие передаёт приложению исходное действие системного уведомления, включая
контекст аккаунта, чата и сообщения. Для Telegram/exDesktop это позволяет открыть
нужный диалог; другие приложения поддерживаются, если регистрируют обработчик
`INotificationActivationCallback` и передают контекст в действии баннера.
Discord/Electron может не заполнять действие самого баннера: тогда щелчок
передаётся его обработчику по точному Windows Tag исходного уведомления.
Обработчик находит соответствующее сообщение в памяти Discord и открывает его чат.
Listener не отдаёт это действие: программа читает одну соответствующую запись
локального хранилища Windows в режиме только чтения, сверяя AppID, ID, время и
содержимое. Схема хранилища не документирована и может измениться в Windows.
Для доступа к обработчикам обычных приложений используется включённый в комплект
скрытый вспомогательный процесс. Для обычных приложений он работает вне контекста
MSIX, для Telegram из Microsoft Store — в контексте точного исходного пакета через
системный механизм запуска Desktop Bridge. Это также различает одинаковые CLSID
у обычного Telegram и его форков. Помощник не открывает консоль, не
требует отдельной установки или .NET; данные передаются через канал текущего
пользователя и остаются в памяти. Копия помощника в локальном кэше приложения
сверяется по SHA-256 с файлом внутри подписанного пакета.
Если контекст удалён, не совпал или обработчик недоступен, открывается само
приложение по Windows AppID. Кнопки ответа/прочтения не вызываются вместо нажатия на баннер.
Старые сообщения при запуске/изменении фильтров и сообщения, полученные во время
«Не беспокоить»/игрового режима, не воспроизводятся после включения показа.
Текст уведомлений и переписка не записываются в журнал. Технический журнал
`notifications.log` содержит ID, время создания, состояние фильтров и этапы
обработки, ограничен 256 КБ; контрольные суммы текста хранятся только в памяти.
Обновление содержимого уведомления с прежним ID распознаётся как изменение.
Для зависшего чтения Windows предусмотрена отмена через 5 секунд и повторный опрос;
временная ошибка не превращает следующее уведомление в историю при запуске.

В Telegram Desktop откройте «Настройки → Уведомления и звуки» и включите
«Уведомления на рабочем столе». Ниже, в разделе «Взаимодействие с системой»,
включите «Использовать уведомления Windows». Если установлено несколько клиентов
Telegram, проверьте настройки именно того клиента, который получает сообщения.
Программа читает уведомления, опубликованные в центре уведомлений Windows.
Собственные всплывающие окна мессенджеров, не переданные Windows, недоступны
этому API. При включённом перехвате островок отключает `ShowBanner` у выбранных
приложений; `Enabled` и `ShowInActionCenter` не меняются, история остаётся в Windows.
Это системная настройка Shell в HKCU, а не документированный API подавления баннеров.
Манифест MSIX исключает ветку Notifications/Settings из виртуализации на Windows 11;
на Windows 10 отключает виртуализацию реестра через desktop6. Для этого объявлена
возможность unvirtualizedResources. Доступ к файловым данным сохраняет прежние правила MSIX.
При выключении фильтра, потере доступа и штатном выходе исходные значения
восстанавливаются. Отдельный процесс восстанавливает их после аварийного выхода;
журнал `%LOCALAPPDATA%/DynamicIslandWin/notification-banners.json` сохраняет значения
для восстановления после перезагрузки. При удалении приложения сначала выйдите
через трей либо используйте `Uninstall.ps1`, чтобы восстановить настройки.
Вновь зарегистрированные источники добавляются при следующем опросе; самый первый
баннер нового источника может успеть появиться. Системные сообщения Windows не перехватываются.
Те же условия относятся к exDesktop: включите его системные уведомления Windows.
Добавление клиента в фильтр не позволяет читать его собственные всплывающие окна.

Время от получения сообщения мессенджером до создания системного уведомления
зависит от самого клиента. Например, Telegram может откладывать уведомление,
если активен другой сеанс; островок видит его после публикации в Windows.
В журнале отображается `latencyMs` — задержка от создания уведомления Windows
до его показа на островке, без текста сообщения.

Для проверки используйте новое входящее сообщение в чат, который не открыт
на компьютере. Существующие сообщения из центра уведомлений при запуске
островка намеренно не повторяются.

Документация Microsoft: https://learn.microsoft.com/windows/apps/develop/notifications/app-notifications/notification-listener

## Внешний вид

«Настройки → Внешний вид → Liquid Glass» включает полупрозрачный материал,
градиентные грани и блик, следующий за курсором. Эффект также применяется к
карточкам и боковым капсулам. Это оформление WPF без захвата экрана и без
размытия рабочего стола средствами DWM. При выключении возвращаются плотные поверхности.

Все 12 тем используют общую палитру для настроек, главной панели, погоды,
буфера обмена, уведомлений, полей ввода, переключателей и контекстного меню.
В светлых темах текст и акценты становятся тёмными. Цвета фирменных значков
приложений и индикаторов состояния сохраняются.

Контекстное меню использует скруглённую панель с иконками, подсказкой горячей
клавиши и отметкой активного игрового центра. Игровая панель показывает FPS,
CPU, температуру и GPU в отдельных карточках с ровными цифровыми колонками.

Liquid Glass также применяется к уведомлениям, панели звонка Discord,
контекстному меню и списку языков. Выключение эффекта убирает блики со всех панелей.

## Запись экрана

Кнопка «Запись экрана» открывает выбор области видеозаписи в актуальных «Ножницах»
Windows 11. Выберите область и нажмите «Начать»; остановка и звук управляются
системной панелью. После остановки приложение сохраняет MP4 в `Видео/OC - Dynamic Island`
и выделяет файл в Проводнике. Отмена не создаёт файл. Пока запись открыта,
повторное нажатие блокируется. Требуется установленный пакет MSIX и версия
«Ножниц» с поддержкой протокола `ms-screenclip://capture/video`.
Кнопки «QR-код» и «Текст с экрана» удалены вместе с их переключателями.

## «Не беспокоить»

Приложение читает **действующий** профиль Windows, включая автоматические правила,
а переключатель меняет выбранный системный профиль через Shell COM.
Изменение интерфейса подтверждается повторным чтением Windows, ошибки показываются.
Изменения из системного центра уведомлений отражаются в островке примерно за 160 мс.
Выключение индикатора скрывает значок и сообщения о смене режима; подавление
уведомлений продолжает учитывать действующий профиль Windows.

Игровой режим запоминает исходный профиль и восстанавливает его при выключении
и штатном выходе. Если пользователь изменил режим в Windows или на островке,
программа не отменяет его выбор. При аварийном завершении восстановление
не гарантируется. Сброс настроек островка не выключает системный режим.

У Windows нет документированного общедоступного API для переключения DND.
Используется изолированный недокументированный интерфейс `IQuietHoursSettings`:
https://withinrafael.com/2019/09/19/determine-if-your-app-is-in-a-focus-assist-profiles-priority-list/
Он проверен на Windows build 26300 на этой машине. Совместимость с будущими
сборками Windows не гарантируется; при недоступности интерфейса переключатели
блокируются, вместо отображения вымышленного состояния. Записи WNF и глобальные
реестровые настройки уведомлений больше не изменяются при запуске.

Ошибки интеграций: `%LOCALAPPDATA%/DynamicIslandWin/Logs/integration.log`.
Этапы обработки уведомлений: в той же папке `notifications.log`. Windows может
перенаправить эти файлы установленного MSIX в
`%LOCALAPPDATA%/Packages/DynamicIslandWin_v3xtbmbqg7et2/LocalCache/Local/DynamicIslandWin/Logs`.

Инструменты MakeAppx и SignTool берутся из официального пакета Microsoft SDK
BuildTools, закреплённого по версии. Для собственного сертификата передайте
`-PfxPath`; пароль можно задать переменной `DYNAMIC_ISLAND_PFX_PASSWORD`.
Номер версии и Publisher подставляются в манифест автоматически.
Сборка не устанавливает пакет и не изменяет хранилища сертификатов компьютера.
