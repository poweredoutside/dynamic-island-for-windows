# OC - Dynamic Island — история изменений

## 1.1.5 — 17 ноября 2026

Первый публичный выпуск OC - Dynamic Island для Windows x64.

- Источник обновлений по умолчанию: [poweredoutside/dynamic-island-for-windows](https://github.com/poweredoutside/dynamic-island-for-windows).
- Самостоятельный графический установщик `ocdynamicisland.exe`, без консоли
  и отдельной установки .NET.
- Загрузка обновлений из GitHub Releases с проверкой SHA-256 и подписи издателя.
- Громкость и Mute по событиям CoreAudio: настройка показа в островке с заменой
  системного индикатора для клавиш громкости.
- Исправления обработки кликов, наведения и перетаскивания; снижение фоновой нагрузки.
- Уведомления Telegram, exDesktop, Discord и других приложений с их иконками,
  переходом по исходному действию и временем показа 3–10 секунд.
- Синхронизация системного «Не беспокоить» и восстановление настроек баннеров.
- Liquid Glass, встроенные и свои темы, персонажи, настройка размеров и раскладки.
- Музыка и караоке, микшер приложений, игровой центр, погода, история буфера обмена,
  снимки и запись экрана, календарь, таймеры, Gemini Live и диагностика.

[Полный перечень функций, требований и ограничений](FEATURES.ru.md).

### Установка

Скачайте `ocdynamicisland.exe` из раздела Releases и запустите установку.
На Windows 10 2004+ / Windows 11 нужен процессор x64. Для записи экрана требуются
актуальные «Ножницы» Windows 11. Установщик подписан сертификатом разработки:
при первой установке может потребоваться подтверждение доверия сертификату.
Поверх прежней версии обновление сохраняет настройки.

В приложении: «Центр → Обновления → Проверить». Обновления устанавливаются
по действию пользователя; дополнительные программы для загрузки не нужны.
