OC - Dynamic Island для Windows 10/11 (x64)

Windows 1.1.31 — умный ассистент Gemini и переход в чаты Telegram.

1. Запустите ocdynamicisland.exe и нажмите «Установить». Всё необходимое включено в этот
   файл: его можно перенести отдельно. Консоль не открывается.
2. Для тестовой сборки Windows может запросить права администратора для доверия
   включённому сертификату подписи (TrustedPeople). При отмене установка прекратится.
3. После установки нажмите «Готово». Флажок запуска приложения можно снять.
   При первом запуске разрешите доступ к уведомлениям в системном запросе.

Для температуры CPU отметьте флажок PawnIO, если драйвер ещё не установлен. Подписанный драйвер
включён в установщик; Windows запросит права администратора. Отмена этого
запроса сохраняет установленное приложение; повторить установку драйвера можно
в игровом центре. FPS включается вместе с игровым HUD и требует подтверждения
Windows для помощника ETW. Исходники драйвера с зависимостями приложены как
PawnIO-2.2.0-source.zip в том же выпуске GitHub.

При обновлении установщик сам завершает работу современной версии приложения.
Если старую версию не удалось закрыть, выйдите из неё через меню значка в трее.
Setup.cmd и Install.ps1 оставлены для ручной установки из полного комплекта.

После добавления сертификата можно открывать DynamicIsland.msix напрямую.
Для обновления поверх установленного приложения запустите ocdynamicisland.exe.
Локальные пересборки с тем же номером приложения используют следующую ревизию MSIX,
поэтому Windows обновляет пакет и сохраняет данные приложения.
Удаление: Windows → Параметры → Приложения → OC - Dynamic Island → Удалить.
Также можно запустить Uninstall.ps1 от текущего пользователя.

Telegram Desktop / exDesktop: в «Настройки → Уведомления и звуки» включите
«Уведомления на рабочем столе» и «Использовать уведомления Windows».
На островке появляются уведомления, переданные в центр уведомлений Windows.
Собственные всплывающие окна мессенджеров этим разрешением не читаются.
При включённом перехвате баннеры выбранных приложений скрываются, история
Windows сохраняется. При отключении перехвата и выходе настройки восстанавливаются.
Перед удалением выйдите через трей либо используйте Uninstall.ps1.
В «Поведение» настраивается время показа 3–10 секунд. Нажатие открывает
приложение-источник; конкретный чат не всегда доступен через API Windows.
Liquid Glass и общая палитра тем настраиваются в разделе «Внешний вид».

Для публичного распространения используйте доверенный сертификат или Microsoft Store.
Включённый сертификат предназначен для тестирования и локальной установки.
